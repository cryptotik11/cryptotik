# كيف تحصل على مفتاح GitHub (دقيقتان)

> المفتاح = «كلمة مرور مؤقتة» تسمح لبرنامج بالرفع على حسابك **دون** إعطائه كلمة سرك.
> GitHub لم يعد يقبل كلمة السر العادية عند الرفع، فالمفتاح إلزامي.

---

## ⚠️ أولًا: تأكد أنك داخل الحساب الصحيح

افتح https://github.com/settings/profile

يجب أن يظهر في الأعلى **`cryptotik11`**. إن ظهر اسم آخر → سجّل الخروج وادخل بالحساب الذي يملك المستودع `cryptotik11/cryptotik`.

---

## الطريقة أ — المفتاح الكلاسيكي (الأسهل: 5 نقرات) ⭐ مُوصى بها

### 1. افتح الرابط
👉 **https://github.com/settings/tokens/new**

### 2. املأ الحقول الثلاثة

| الحقل | ما تكتبه |
|---|---|
| **Note** | `crypto-pulse` |
| **Expiration** | `7 days` |
| **Select scopes** | ✅ أشّر `repo` (المربع الكبير كاملًا) |
| | ✅ أشّر `workflow` (تحته بقليل) |

> **لماذا `workflow`؟** لأن مشروعنا يحتوي مجلد `.github/workflows/`، وGitHub يرفض رفعه بدون هذه الصلاحية.

📸 الشاشة ستبدو هكذا: قائمة طويلة من المربعات — أولها `repo` وآخرها أشياء مثل `admin:org`. أنت تحتاج أول اثنين فقط.

### 3. اضغط الزر الأخضر
في **أسفل الصفحة**: `Generate token`

### 4. انسخ المفتاح فورًا
سيظهر سطر يبدأ بـ **`ghp_`** بجانبه أيقونة نسخ 📋
**انسخه الآن — لن يظهر مرة أخرى أبدًا.**

---

## الطريقة ب — المفتاح المقيّد Fine-grained (أكثر أمانًا، خطوات أكثر)

مناسب إن أردت مفتاحًا لا يصل إلا لهذا المستودع وحده.

### 1. افتح
👉 **https://github.com/settings/personal-access-tokens/new**

### 2. املأ

| الحقل | القيمة |
|---|---|
| **Token name** | `crypto-pulse-deploy` |
| **Expiration** | `7 days` |
| **Repository access** | `Only select repositories` → اختر **cryptotik11/cryptotik** |

### 3. أضف الصلاحيات
اضغط **`+ Add permissions`** وأضف ثلاثًا بمستوى **`Read and write`**:

1. `Contents`
2. `Workflows`
3. `Actions`

(`Metadata: Read-only` تُضاف تلقائيًا — اتركها)

### 4. أنشئ وانسخ
`Generate token` → انسخ المفتاح، يبدأ بـ **`github_pat_`**

---

## كيف تعرف أن المفتاح صحيح؟

| البادئة | النوع | يعمل مع سكربت النشر؟ |
|---|---|---|
| `ghp_` | Classic | ✅ |
| `github_pat_` | Fine-grained | ✅ |
| `gho_` | OAuth (تطبيق) | ❌ لا تستخدمه |

طول المفتاح عادة 40 حرفًا أو أكثر. إن كان أقصر من ذلك فأنت نسخت جزءًا فقط.

---

## أخطاء شائعة تمنعك

| المشكلة | الحل |
|---|---|
| زر Generate token لا يعمل / «You must verify your email» | فعّل بريدك: https://github.com/settings/emails |
| لا أجد `workflow` في القائمة | ابحث عنها بالكيبورد (Ctrl+F) داخل صفحة الصلاحيات |
| نسخت المفتاح ثم اختفى | لا يمكن استرجاعه — أنشئ واحدًا جديدًا |
| أدخلت كلمة سر حسابي بدلًا منه | لن يعمل — لازم المفتاح |

---

## 🔒 بعد انتهاء النشر

احذف المفتاح من: https://github.com/settings/tokens
(سيكون بجانب `crypto-pulse` → `Delete`)

المفتاح صالح 7 أيام كحد أقصى، والمهام المجدولة تعمل على GitHub دون الحاجة له بعد النشر — هو مطلوب مرة واحدة فقط للرفع الأول.
